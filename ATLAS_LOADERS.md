# Atlas loader integrations

Atlas creates loader-ready instances from the **Add Instance → Custom** page.
The integration mode follows the format officially distributed by each loader.

| Loader | Atlas install mode | Source |
| --- | --- | --- |
| Legacy Fabric | Versioned component | Legacy Fabric metadata API |
| Babric | Versioned component | Babric metadata API |
| Better Than Adventure | Complete instance import | Official BTA MultiMC/Prism ZIP |
| Ornithe | Versioned component | Ornithe v3 metadata API |
| Rift | Versioned component for Minecraft 1.13 | Official Rift release |
| Cleanroom | Complete instance import | Official Cleanroom MMC ZIP |
| NilLoader | Universal Java-agent component | Official NilLoader Prism component |
| Cursed Fabric | Complete legacy instance import | Official BTW Cursed Fabric MMC ZIP |
| FoxLoader / ReIndev | Complete instance import | Official FoxLoader MMC ZIP |
| FishModLoader / MITE | Versioned component for Minecraft 1.6.4 | Official combined MITE/FML release |

Legacy Fabric, Babric, and Ornithe profiles are generated by
`AtlasMeta/build_atlas_loaders.py`. The generator binds every loader profile to
the exact Minecraft version reported by the upstream project, preventing Atlas
from offering incompatible combinations.

Complete-instance integrations intentionally use `InstanceImportTask`. These
projects ship custom Minecraft patches, local libraries, or jar mods that
cannot safely be represented as an ordinary loader layered onto an arbitrary
vanilla instance.
